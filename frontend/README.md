# Smart-Stock frontend

React 18 + Material UI (RTL) client for the Smart-Stock API.

```bash
npm install
cp .env.example .env.local   # point REACT_APP_API_URL at your backend
npm start                    # http://localhost:3000
npm test                     # unit tests
npm run build                # production build in ./build
```

See the [main README](../README.md) for the full setup.
